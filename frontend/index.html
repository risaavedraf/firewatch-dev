DEMO SINTÉTICA
!

Entrada de demostración: todavía no hay ingestión de datos reales. La API clasifica un lote sintético con una regla académica propia, declarada como no oficial y no calibrada contra incendios observados. Esta vista no predice fecha ni lugar, no emite alertas y no sustituye a CONAF ni a SENAPRED.

Cada comuna con un lote publicado conserva su color según el último lote de esa zona, aunque no esté seleccionada; el gris neutro significa que esa comuna no tiene lote publicado.
