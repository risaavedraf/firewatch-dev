## Specs

**S1 — Commit base único.** «Clean the working tree of anything sensitive/heavy, then create **one baseline commit** of the current state (Conventional Commit message).»

**S2 — READMEs vivos y consistentes.** «Bring root and per-area READMEs (`README.md`, `frontend/README.md`, `backend/README.md`, `backend/docs/**`) up to date and self-consistent.»

**S3 — Enlaces e índice.** «Verify all relative links resolve (zero broken) and that `odd/tasks/README.md` agrees with the documents it indexes.»

**S4 — `.gitignore`.** «Ensure `.gitignore` prevents any generated/heavy/sensitive artifact from being committed (explicitly evaluate `tmp/`).»

**S5 — Reporte.** «Report back: exact modified paths; the link-check command and its exit code; `git status --short` after the commit; what you deliberately left out and why; contradictions found but not fixed (out of scope).»

**S6 — Repositorio destino y acceso.** Pedido textual del usuario: «bro, el repo es este git@github.com:risaavedraf/firewatch-dev.git, tenemos que darle acceso a la cuenta de este pc porfa». Decisiones del usuario sobre las dos preguntas planteadas: cuenta **`risaavedraf`**; autenticación **«SSH con clave ed25519 nueva»**.

**S7 — Superficies de edición.** Permitidas: `README.md`, `frontend/README.md`, `backend/README.md`, `backend/docs/**`, `odd/**`, `.gitignore`, `.gitattributes`, `.github/**`. Prohibidas: `push`, creación del repositorio remoto, publicación, `.env*` y variantes, `backend/docker-compose.yml`, credenciales, volúmenes, ejecutar Docker o migraciones, y las superficies reservadas de la sesión hermana `01a13736` (`odd/tasks/react-frontend-plan.md`, `frontend/docs/react-migration-plan.md`).

**S8 — Afirmaciones prohibidas.** El repositorio no puede afirmar datos reales, calibración científica, aprobación de producción ni frontend React implementado. Es un MVP sintético de demostración y el frontend actual es JavaScript sin framework.

**S9 — Duplicado pendiente de decisión humana.** No consolidar ni borrar `odd/tasks/backend-hardening/` (12 archivos) frente a su copia verificada en `odd/tasks/security/backend-hardening/`; solo declararlo.
